# «Счастье есть» — сайт-визитка: анализ карточки и сборка

Лофт-пространство, кофейня и мастер-классы **«Счастье есть»** (Орехово-Зуево, ул. 1905 года, 2).
Внутри — готовый сайт из 8 страниц, локальная админ-панель с приёмом заявок, набор фотографий
по блокам и пошаговая инструкция переноса на Tilda.

---

## 1. Быстрый старт

```bash
cd /home/user/RESONANSE
python3 app.py
```

| Что | Адрес |
|---|---|
| Сайт | http://localhost:8080/ |
| Админ-панель | http://localhost:8080/admin/ |
| Пароль по умолчанию | `schastye2026` (печатается в консоли при первом запуске) |

Порт меняется переменной `PORT`: `PORT=3000 python3 app.py`.
Свой пароль можно задать при первом запуске: `ADMIN_PASSWORD=мойпароль python3 app.py`,
или сменить его в админке → «Настройки».

## 5. Админ-панель

Вход по паролю (cookie-сессия на 24 часа). Вкладки:

1. **Обзор** — всего заявок, новые, в работе, подписки, последние 5 заявок.
2. **Заявки** — поиск по имени/телефону/почте, фильтр по статусу, смена статуса
   (новая → в работе → забронирована / отказ), удаление, экспорт CSV.
3. **Фотографии** — 21 слот под все блоки: ссылка или загрузка файла, кнопка
   «Подставить фото из карточки» возвращает исходные ссылки.
4. **Акции** — добавить/удалить/отредактировать, порядок как в списке; сразу
   появляются в блоке «Сейчас действует» на главной.
5. **Настройки** — смена пароля, описание хранения данных.

**Где лежат данные** (папка `data/`):

```
data/
├── leads.json      заявки
├── content.json    фото и акции
├── auth.json       соль и хеш пароля
└── uploads/        загруженные изображения
```

Резервная копия — копия папки `data/`.

## 6. Приём заявок и сбор контактов

* Все формы (`data-lead-form`) отправляют `POST /api/leads` с JSON:
  `form`, `name`, `phone`, `email`, `topic`, `date`, `guests`, `message`,
  `subscribe`, `consent`, `page`, `createdAt`.
* Сервер валидирует имя, телефон и согласие, пишет заявку в `leads.json`,
  её сразу видно в админке.
* Валидация на клиенте: имя (≥ 2 символов, только буквы), телефон (10–11 цифр,
  маска `+7 (___) ___-__-__`), e-mail, дата не в прошлом, обязательное согласие.
* Если сервер недоступен (например, открыт `file://`), заявка сохраняется
  в `localStorage` — ничего не теряется молча.
* **Сбор контактов:** чекбокс «Хочу получать письма…» в форме заявки, отдельная
  форма подписки в подвале (вкладка «Подписка») и счётчик подписок в админке.
* Перенаправление в Telegram/CRM: заменить `endpoint` в `site/assets/js/main.js`
  на адрес вебхука — формат payload описан выше.

## 7. Приветственная анимация

Полноэкранная заставка: круг с фото входа, два «слова» с задержкой, подзаголовок,
полоса прогресса. Закрывается через 2,7 с, по клику, кнопке «Пропустить» или `Esc`.
Показывается один раз за сессию (`sessionStorage`), отключается при
`prefers-reduced-motion`. Для каждого захода — `welcomeAlways: true` в `main.js`.

## 8. Тильда

Тильда — сторонний редактор без API для автоматической публикации, поэтому
в репозитории лежит **`TILDA_SETUP.md`**: пошаговая сборка тех же 8 страниц,
настройка форм (Tilda Forms, Telegram-бот, CRM, Google Sheets), сбор контактов,
админка Тильды и код приветственной анимации для блока T123.

## 11. Юридические заметки

* Цены, состав меню и пакеты — **модельные оценки**, не прайс заведения; перед
  публикацией нужно согласовать.
* Отзывы приведены из открытых источников с указанием источника. Для публикации
  лучше вставить виджет отзывов Яндекса или взять разрешение.
* `privacy.html` — шаблон, а не юридическое заключение: заполните реквизиты
  оператора и проверьте текст у юриста.
* Фотографии принадлежат заведению и авторам снимков; при публикации на своём
  домене лучше загрузить оригиналы в медиатеку.
